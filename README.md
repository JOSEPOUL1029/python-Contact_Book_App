# Contact Book (Tkinter)

A simple desktop Contact Book application built using Python and Tkinter.  
It allows users to add, view, search, and delete contacts using a graphical interface.

# Features
- Add new contacts (Name, Phone, Email)
- View saved contacts in a list
- Search contacts by name
- Delete selected contacts
- Click a contact to view full details
- Responsive layout with scroll support

#Technologies Used
- Python 3
- Tkinter (GUI library)

#How to Run

1. Make sure Python 3 is installed on your system
2. Download or clone this repository
3. Open terminal in the project folder
4. Run the application:

```bash
python python contact_book.py
